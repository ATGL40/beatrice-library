            提交给碧翠子禁书库

            文件里只有作品 id、你的星级、你对神作 / 神作提名的投票和理由、你的黑榜和理由，没有名字、评论和别的标记。汇总后作为公开数据（ODbL 1.0）随数据包发布：星级只公开每部的平均分和人数，票只公开支持 / 反对的票数，黑榜只公开每部的人数（人多的作品会标上「多人拉黑」）。软件不联网，不会替你发送：保存或复制后，贴进 GitHub 表单，或作为附件发邮件到 beatrice2library@gmail.com。通过 GitHub 提交的理由会公开；想私下说明理由请用邮件。

            我的星级

            默认全部提交，取消勾选的这次不提交。

              神作投票 / 复议

              神作提名由算法提名，社区投票达到门槛后升为神作；神作反对票够多会撤下。反对要写理由（至少 20 字），支持可以不写。投票存在本机，以后可以改。

                我的黑榜

                默认全部提交，取消勾选的这次不提交；理由一起提交（在作品详情页里改）。

                  添加为我的游戏

                  图鉴里没有的游戏，自己添加进来：能启动、记游玩时长、标记、评分、分档，不参与综合榜，也不会提交。

                  封面

                  封面只认 jpg / png / webp，最多 10 MB；软件会复制一份到自己的文件夹，原图不动。

                  导入评分文件

                  合并时只补上你空着的内容，你已经填过的状态、星级、评论都不会被改。

                  找游戏

                  在设置里添加的游戏文件夹里找，可以模糊搜索；不在这些文件夹里的，点「自己选启动程序」。
